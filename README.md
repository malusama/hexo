# Historical Malu Hexo blog

Use Node.js 24. This repository contains the older Hexo content, while the current https://malu.moe site is generated by Hugo and published from [malusama.github.io](https://github.com/malusama/malusama.github.io).

```sh
npm ci --ignore-scripts
npm audit
npm run build
npm run server
```

Do not deploy this historical content over the current live blog. See [the dependency/security upgrade notes](docs/security-upgrade.md) for nested theme build instructions and validation scope.
